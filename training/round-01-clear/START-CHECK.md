# B7-1 — 시작 전 지식 체크

이 문서는 B7-1 Term Project를 시작하기 전에 **Git 협업·Web·DB·배포·AI API를 하나의 서비스로 연결할 최소 준비 수준**을 확인하는 자가진단입니다. 공식 평가나 Runtime Gate가 아닙니다.

## 선행 학습

- **필수 선행 미션:** 없음
- **권장 선행 미션:** B2-2, B4-1, B5-1, B6-1, B6-2
- **있으면 좋은 선행 지식:** Git 협업, Frontend/Backend, DB, 배포, AI API의 기본 흐름

## 자가진단

- [ ] branch/commit/PR의 기본 협업 흐름을 이해한다.
- [ ] 브라우저(Frontend)와 서버(Backend)가 요청/응답으로 통신한다는 점을 이해한다.
- [ ] DB에 사용자와 대화 데이터를 저장하는 이유를 설명할 수 있다.
- [ ] 회원별 데이터가 섞이지 않도록 사용자 구분이 필요하다는 점을 이해한다.
- [ ] 환경변수로 API Key 같은 Secret을 관리해야 하는 이유를 알고 있다.
- [ ] AI API에 요청을 보내 응답을 받아 화면에 보여 주는 전체 흐름을 대략 설명할 수 있다.
- [ ] 로컬에서 동작하는 서비스와 외부에 배포된 서비스의 차이를 이해한다.

## 판단 방법

- 대부분 `예`라면 `BEGINNER-GUIDE.md`로 바로 진행합니다.
- 부족한 영역이 1~2개라면 B7-1을 진행하면서 해당 권장 선행 미션의 관련 부분만 보충하는 방식이 효율적입니다.
- Git/Web/DB/Deploy/AI API가 모두 낯설다면 권장 선행 미션을 영역별로 먼저 경험하면 Term Project의 시행착오를 크게 줄일 수 있습니다.

> **권장 선행 미션을 모두 CLEAR해야 B7-1을 시작하는 것은 아닙니다.** 핵심 개념을 이미 이해하고 있다면 바로 B7-1에 진입하고 부족한 영역만 보충합니다.
